# Azure Security Engineering Block 3 — Runtime Security

## Overview

This repository contains my Block 3 runtime security implementation focused on Microsoft Sentinel, Microsoft Entra security monitoring, KQL, detection engineering, SIEM operations, incident investigation, and SOAR automation.

Unlike Block 2, which focused on infrastructure deployment and security configuration, Block 3 focuses on monitoring activity after deployment and detecting security-relevant events.

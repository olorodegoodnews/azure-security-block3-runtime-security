# Microsoft Sentinel

This directory contains documentation for the Microsoft Sentinel implementation used in Block 3.

## Environment

- **Log Analytics Workspace:** `law-block3-sentinel-security`
- **Resource Group:** `rg-block3-runtime-security`
- **Primary Log Source:** Azure Activity Logs
- **SIEM Platform:** Microsoft Sentinel

## Sentinel Capabilities Implemented

The Block 3 Sentinel environment was used for:

- Azure Activity log ingestion
- KQL log analysis
- Custom detection engineering
- Scheduled analytics rules
- Security alert generation
- Incident creation and investigation
- Entity mapping
- Custom alert details
- SIEM ingestion analysis
- SOAR automation

## Custom Detections

Four custom analytics rules were fully validated:

1. Azure Resource Group Deletion
2. Azure RBAC Role Assignment Change
3. Azure Policy Assignment Change
4. Azure NSG Security Rule Change

An additional Azure Key Vault Access Policy Change rule was also configured as extended detection work.

The KQL detection queries are stored in:

`../detections/`

## SOAR Automation

Microsoft Sentinel automation was configured for incidents generated by:

`Azure NSG Security Rule Change`

The automation automatically adds the following incident tag:

`Network-Security`

The automation documentation is stored in:

`../soar/nsg-incident-automation.md`

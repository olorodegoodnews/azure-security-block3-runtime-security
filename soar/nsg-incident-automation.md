# NSG Incident Automation

## Purpose

This automation provides automatic triage for Microsoft Sentinel incidents generated by the `Azure NSG Security Rule Change` custom analytics rule.

## Trigger

The automation rule runs when a new Microsoft Sentinel incident is created.

## Condition

The incident must be generated by:

`Azure NSG Security Rule Change`

## Automated Action

The automation rule automatically adds the following tag:

`Network-Security`

This allows network-related security incidents to be identified and prioritized without requiring an analyst to manually classify each incident.

## Validation

I generated a controlled NSG security-rule change in Azure.

The Azure Activity event was ingested into Microsoft Sentinel and detected by the custom NSG analytics rule.

Microsoft Sentinel created an incident, after which the automation rule automatically added the `Network-Security` tag.

## Workflow

Azure NSG Rule Change  
→ Azure Activity  
→ Microsoft Sentinel  
→ Custom Analytics Rule  
→ Security Incident  
→ Automation Rule  
→ `Network-Security` Tag
